# Item Project

Servlet/JSP inventory dashboard using Oracle JDBC and simple SQL without an ORM.

## Features

- Email and password login with email OTP verification
- Product CRUD with optional product details
- Category CRUD and product filtering
- Administrator employee management and permissions
- Account details and password change
- Responsive right-side navigation and modal forms

## Oracle

Run the files inside the database folder in numeric order for a new installation.

Application schema:

- Username: ITEM_PROJECT_USER
- Service: ORCLPDB

## SMTP

The application uses the same configuration names as E-Wallet:

- SMTP_HOST
- SMTP_PORT
- SMTP_USERNAME
- SMTP_PASSWORD
- SMTP_FROM_NAME
